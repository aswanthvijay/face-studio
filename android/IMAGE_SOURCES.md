# Bundled photography sources

All six bundled stock photographs replace private project images. The login hero, guest sample and UI-test fixture use cc0_studio.jpg. Each source page explicitly displayed CC0 when checked on 15 October 2026. This record applies to these individual photographs, not every image hosted on those sites.

The studio image uses a 1280-pixel rendition supplied by the source CDN; the other files are downloaded originals. No local pixel edits were made. Style cards use Coil to sample images to their displayed size, and the small bundled hero uses a native Compose image. The source URLs, download URLs and SHA-256 checksums are also packaged in assets/image_licenses.json.
